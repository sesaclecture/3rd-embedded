-------------

ros2 topic pub /cmd_vel geometry_msgs/msg/Twist
        ↓
controller node
        ↓
Twist callback
        ↓
linear.x / angular.z 해석
        ↓
좌/우 모터 PWM 변환
        ↓
로봇 주행


linear.x  > 0 : 전진
linear.x  < 0 : 후진
linear.x == 0 : 전후 이동 없음

angular.z > 0 : 좌회전
angular.z < 0 : 우회전
angular.z == 0 : 회전 없음
